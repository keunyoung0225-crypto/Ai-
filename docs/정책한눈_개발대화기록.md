**빌드 도구 없이 HTML·CSS·JavaScript만으로 만들고, 정해진 항목은 설정 파일 한 곳에 모아서 관리하는 구조예요.**

   imageUrl: 'https://keunyoung0225-crypto.github.io/Ai-/images/ad-side.png',

## Q68. vercel에서 방문자수 카운팅은 중복카운팅 인가요?

*2026.10.14 18:10*

**질문**

> vercel에서 방문자수 카운팅은 중복카운팅 인가요?

**답변**

두 가지 숫자가 있어서, **어떤 숫자를 보느냐에 따라 달라요.**

| Vercel 화면의 숫자 | 중복 여부 | 예시 |
|---|---|---|
| **Visitors (방문자)** | 같은 사람은 **하루에 한 번만** 셈 | 한 사람이 오늘 5번 들어와도 1명 |
| **Page Views (페이지 조회수)** | 들어올 때마다 **모두** 셈 (중복 포함) | 같은 사람이 5번 들어오면 5회 |

**Visitors가 사람을 구분하는 방법**

- 쿠키를 쓰지 않고, 접속 정보(IP 주소와 브라우저 정보)로 익명 식별값을 만들어 같은 사람인지 구분해요. 이 식별값은 하루가 지나면 새로 만들어져요.
- 그래서 오늘 왔던 사람이 내일 다시 오면 **다시 1명으로** 셈해요. "7일간 방문자"는 서로 다른 사람의 수라기보다 **하루 방문자를 더한 값에 가깝다**고 보시면 돼요.
- 같은 사람이라도 PC와 휴대폰으로 각각 들어오면 **2명**으로 셈해요.
- 반대로 같은 회사나 와이파이를 쓰고 같은 기종·브라우저를 쓰는 여러 사람은 드물게 1명으로 합쳐질 수 있어요.

**우리 사이트에서 알아 둘 점**

- 사이트 안에서 지역을 누르거나 검색하면 화면만 바뀌고 페이지를 새로 열지는 않아요. 그래서 조회수는 늘지 않아요. **사이트에 들어온 횟수**만 조회수로 셈해요.
- 경진대회 자료에 쓰실 때는 **Visitors(방문자 수)**를 쓰는 게 정확해요.
    - 예: "공개 후 ○일간 하루 평균 방문자 ○명, 총 페이지 조회 ○회"
- 정확한 계산 방식은 Vercel 공식 안내를 기준으로 하는데, 이 환경에서는 Vercel 문서를 직접 열어 확인하지 못했어요. 세부 동작은 Vercel이 바꿀 수 있어요.

**답변**

## 단어별 뜻

| 단어 | 뜻 |
|---|---|
| **바이브코딩** | 코드를 직접 짜지 않고, AI에게 원하는 것을 말로 설명하며 개발하는 방식 |
| **MVP** (Minimum Viable Product, 최소 기능 제품) | 꼭 필요한 핵심 기능만 넣어 실제로 써 볼 수 있게 만든 첫 버전 |
| **직접 구축** | 외주나 개발자에게 맡기지 않고 본인이 만들었다는 뜻 |

## MVP를 조금 더 풀면
처음부터 모든 기능을 다 갖춘 완성품을 만드는 대신, **"이 서비스가 정말 쓸모 있는지 확인할 수 있을 만큼만"** 빠르게 만들어 사람들에게 써 보게 하는 것입니다. 그 반응을 보고 기능을 더하거나 고쳐 나갑니다.
